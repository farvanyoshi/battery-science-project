# Evaluating the Potential of Zinc-ion Batteries

A high school science project by Nirvan Joshi and Sebastian Ruiz (2024–25), written up as a research paper and
typeset with [Typst](https://typst.app).

Zinc-ion batteries were built from consumer-grade materials: a zinc foil anode, a cathode paste of activated
carbon and graphite powder (with **manganese dioxide** added in the last version) around a graphite rod, and a
zinc sulfate or **zinc chloride** electrolyte in a 3D-printed casing. Four iterations were discharged across 10,
100 and 1000 Ω loads for up to 8 hours and recharged at constant voltage between discharges. A Vernier LabQuest 2
logged the current and voltage, and an Arduino-timed relay opened the charging circuit every few minutes to read
the EMF. An AA NiMH cell was discharged for comparison.

## Key results

| | Iteration 2 | Iteration 3 | Iteration 4 | Iteration 5 | AA NiMH |
|---|---|---|---|---|---|
| Electrolyte | 1.5 M ZnSO₄ | 1.5 M ZnCl₂ | 3 M ZnCl₂ | 6 M ZnCl₂ | KOH |
| Cathode | carbon + graphite | carbon + graphite | extra graphite | carbon + graphite + **MnO₂** | — |
| Highest terminal voltage (V) | 1.018 | 1.164 | 0.993 | **2.093** | 1.287 |
| Best effective capacity above 0.9 V (A·min) | 0.198 | 0.188 | 0.029 | **1.125** | — |
| Best effective energy above 0.9 V (W·min) | 0.186 | 0.183 | 0.027 | **1.400** | — |

All values are generated in `data/processed/` from the raw Logger Pro files.

- Iteration 1 was used for testing whether the design was feasible and as such proper measurements were not taken
  of the data. For this reason, it is not included in data analysis.
- Only Iteration 5 showed a battery-like discharge. It held above 1.8 V for about 40 minutes across 1000 Ω before
  dropping off, and gave by far the most useful charge and energy.
- Iteration 4 short-circuited on its first discharge: 1.009 A through a nominal 10 Ω load at only 0.094 V.
- Zinc chloride allowed higher voltages than zinc sulfate, but charging Iteration 5 at 2.2–2.4 V released
  chlorine gas.
- Even Iteration 5's second discharge (2.106 A·min, about 35 mAh in 88 minutes) is far from the ~1100 mAh of an
  AA NiMH cell.

## Repository layout

```
paper.typ               document entry point
paper/                  section text (abstract, intro, theory, method, results, discussion, conclusion)
lib/                    shared Typst code: package versions and layout, data access, graph and table builders
data/raw/               the Logger Pro (.cmbl) files as saved (see data/README.md)
data/converted/         the same data exported to CSV, one folder per file
data/original/          values from the submitted paper, transcribed for checking
data/processed/         generated by the analysis pipeline; read directly by Typst
analysis/               `zinclab`: Python pipeline that draws the graphs and checks the paper + tests
tools/cmbl-export/      converter from .cmbl to CSV
assets/figures/         the graphs (generated)
assets/images/          photographs and diagrams
assets/code/            the Arduino sketch that timed the charging circuit
references/refs.bib     bibliography
docs/VERIFICATION.md    every number in the original paper compared with the data
docs/                   project logbook and the one-page abstract
```

## Building

Requirements: [Typst](https://github.com/typst/typst) ≥ 0.15 (tested with 0.15.1). The analysis needs
Python ≥ 3.10 with numpy, matplotlib and scipy (`pip install -r analysis/requirements.txt`). The graphs and
processed data are committed, so the paper builds with Typst alone.

```sh
make            # regenerate data/processed and assets/figures, then build build/paper.pdf
make paper      # only build the paper
make test       # run the analysis tests
make verify     # regenerate docs/VERIFICATION.md
make check      # tests + fail if the committed processed data or report is stale
make convert    # re-export data/raw/*.cmbl into data/converted (slow, rarely needed)
```

You can also build without `make`:

```sh
cd analysis && python -m zinclab build && cd ..
typst compile paper.typ build/paper.pdf
```

On the first compile Typst downloads the packages pinned in `lib/style.typ` (unify, typsium).
GitHub Actions runs the tests and builds the paper on every push. The PDF is attached to each run as an artifact.

### Changing a graph

Each graph is described in `analysis/zinclab/spec.py` (which Logger Pro file, run and column it shows) and drawn
by `analysis/zinclab/plot.py`. The statistics, integrals and curve fits under each graph are typeset by Typst
from `data/processed/`, so they always match the data.

## Data provenance and corrections

The submitted paper used screenshots of Logger Pro graphs and tables worked out in a spreadsheet. The original
data only existed inside the `.cmbl` files, so they were exported to CSV and every graph was redrawn from them.
All 55 sets of statistics and integrals shown on the original graphs are reproduced exactly.

Checking the rest of the paper against the data turned up some errors, which are corrected here:

- **The effective capacity and energy tables were wrong.** The spreadsheet added up the samples instead of
  integrating over time, so the values were 6× (Iteration 2) or 30× (Iterations 3 and 4) too large. Three cells
  also read the wrong columns. The corrected values change one conclusion: Iteration 5, not Iteration 3, had the
  greatest effective capacity and energy.
- Four numbers in the text were wrong, such as 0.02708 A for 0.002708 A and the sampling rate of Iteration 2.
- The internal resistance tables could only be partly checked, because some of the EMF readings they use were not
  saved. They are unchanged.

Every check, each change and its cause are listed in [`docs/VERIFICATION.md`](docs/VERIFICATION.md). The data
decisions are documented in [`data/README.md`](data/README.md).

## Installing Typst

- Prebuilt binary (Linux x86-64):
  ```sh
  curl -L https://github.com/typst/typst/releases/latest/download/typst-x86_64-unknown-linux-musl.tar.xz | tar -xJ -C /tmp
  install /tmp/typst-x86_64-unknown-linux-musl/typst ~/.local/bin/
  ```
- With Rust: `cargo install --locked typst-cli`
- macOS: `brew install typst`. Windows: `winget install --id Typst.Typst`
- Check the install with `typst --version`.
